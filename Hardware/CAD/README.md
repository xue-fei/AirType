## 规格

- 外形：**34 × 26 × 110 mm**，圆角 R4，圆角矩形截面（手持棒）
- 分模面：厚度中面 Z=13，下壳 13mm / 上壳 13mm，止口凹凸配合定位
- 材料：**PETG**（耐温、长期握持不变形）；PLA 亦可但夏天易软
- 打印层高 0.2mm，填充 20%，壁 1.2mm（3 层）；**圆角朝下贴板**减少支撑
- 4×M2 沉头螺丝锁合（上壳沉头孔 + 下壳螺丝柱）

## 关键尺寸（mm）

| 部位 | 尺寸 |
|---|---|
| 电池仓（103040） | 净 30.8 × 40.8 × 11；前后 3mm 挡壁；出线缺口 1.2 宽 |
| SuperMini 板槽 | 间距 22.9 / 宽 1.4 / 深 2.5；天线端净空 ≥8 |
| C口开孔 | 9 × 3，带 1mm 挡边（右侧壁） |
| 出音孔 | Ø4 + 防尘网槽 Ø6.5×1 + 泡棉槽 Ø9×0.8（顶部） |
| PTT / 电源孔 | 侧面按键孔 |

## 装配要点

1. **电池**：103040 塞入下壳电池仓，线从出线缺口引出；**顶部贴分模面，鼓包空间由上壳内腔提供**（合拢后上方是空的，不会压住）。用 1.5mm EVA 泡棉轻压。
2. **SuperMini**：插入上壳板槽（长边沿宽度方向），**天线端朝左、C 口朝右**伸出开孔。板厚约 1.0mm，若实测偏厚/偏松，改 `build_case.py` 里的 `SLOT_W` 重新生成。
3. **充电**：短接 SuperMini 背面 **BOOST 焊点**（100mA→300mA，约 3.5~4h 充满），单 C 口刷机 + 充电 + 日志。不用外挂充放小板。
4. **麦克风**：INMP441 方形模块置于顶部出音孔下，声孔对准 Ø4 孔，加防尘网 + 泡棉垫圈。

## 校验状态

- 上下壳均 **watertight=True / winding 一致**，非流形错误 0
- 包围盒：下壳 34×110×14，上壳 34×110×13.6
- 出音孔贯穿验证：射线检测中心无命中、边缘命中，孔真实贯通
- 电池仓 / 板槽 / C口孔：截面切片确认空腔与开孔存在

## 注意

- **软包电池公差大**，净尺寸以实物卡尺为准；必要时的微调 `BAT_W/L/H` 后重跑脚本。
- 首版建议先打印一件试装，重点核对板槽松紧、C 口对位、电池仓深度，再批量。
